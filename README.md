# Task Manager

This project uses Vite, Vue 3, Vue Router, and Pinia, organized with clean architecture principles.

## Project Structure
- `src/domain`: Business logic, entities, interfaces
- `src/application`: Use cases, services
- `src/infrastructure`: API clients, data sources
- `src/presentation`: UI components, views

## Setup
```
npm install
npm run dev
```

## Features
- Vue Router for navigation
- Pinia for state management
- Clean architecture folder structure

## Next Steps
- Implement domain models and use cases
